# Shubham Personal Workspace

A single-file productivity dashboard for daily tasks, alarms, learning tracks, notes, and personal finance.

## GitHub Pages

The site is deployed from `index.html` by the GitHub Actions workflow in `.github/workflows/pages.yml`.
On first setup, GitHub may require an owner to enable Pages in **Settings → Pages** and set **Build and deployment → Source** to **GitHub Actions**. Then rerun the **Deploy to GitHub Pages** workflow from the **Actions** tab.

## Privacy

This public copy is local-only. Workspace data is stored in the current browser's local storage; it is not shared between visitors or devices. The hard-coded Google Drive file ID and OAuth token entry were removed, and the default ledger entries were cleared. Use the app's manual JSON export or Sync Code tools to move data between devices.
